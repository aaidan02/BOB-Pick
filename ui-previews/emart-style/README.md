# 밥픽 전체 화면 로컬 시안

이마트24의 큰 브랜드 배너, 넉넉한 여백, 카드 구성과 빠른 이동 메뉴를 참고해 밥픽의 주황색과 기존 기능에 맞춘 시안입니다. 원본 사이트의 이미지나 로고는 사용하지 않습니다.

프로젝트 폴더에서 다음 명령을 실행하고 **http://localhost:4175** 를 여세요.

```sh
npm ci
npm run preview:ui
```

- 상단의 **화면 역할**로 방문자·회원·관리자·마스터 화면을 전환할 수 있습니다.
- 메뉴 찾기, AI 대화 예시, 추천 결과·고정·재검색, 찜, 동네 이야기와 글 편집, 문의·신청, 계정, 관리자, 약관을 확인할 수 있습니다.
- **첫 방문 다시 보기**로 자동 사용 안내를 확인할 수 있습니다. 일반 방문에서는 브라우저당 한 번 자동으로 열리고 `?`로 다시 열 수 있습니다.
- 데이터는 컴퓨터 안에서 실행하는 임시 데이터베이스에 저장합니다. 종료하면 초기화되며, Supabase·Gemini·네이버 지도 등 운영 서비스에 요청하지 않습니다. AI는 예시 규칙으로 로컬 음식점을 고르고 지도는 배치용 그림입니다.
- 기본 홈페이지와 다른 로컬 주소를 사용하므로 기존 로그인·방문 기록에 영향을 주지 않습니다. 운영용 환경 파일과 API 키는 읽지 않습니다.

`Ctrl+C`로 종료합니다. 로컬 시안은 Vercel 빌드에 포함되지 않습니다.
